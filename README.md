# 🚀 TraceLink AI Suite

An enterprise-grade **AI-powered SaaS platform** for intelligent meeting management, transcript analysis, and data validation. Built with a modern multi-page web architecture.

## ✨ Features

- **AI Minutes Generator** — Automatically generate structured meeting minutes from transcripts
- **Zoom Meeting Intelligence** — Analyze and extract insights from Zoom meeting data
- **Transcript Viewer** — Interactive viewer for meeting transcripts with AI-powered highlights
- **Data Validation Engine** — Validate and clean data pipelines with configurable rules
- **Platform Overview** — Unified dashboard for all AI tools
- **Docker Support** — Containerized deployment for scalable production environments
- **Local Network Deployment** — Run entirely on your local network for data privacy

## 🚀 Getting Started

### Option 1: Run Locally

```bash
# Clone the repository
git clone https://github.com/PaarthSuwi/website.git
cd website

# Install dependencies
npm install

# Start the development server
npm start
```

### Option 2: Docker Deployment

```bash
# Build and run with Docker Compose
docker compose up --build
```

Open `http://localhost:3000` in your browser.
